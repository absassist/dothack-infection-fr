# Glossaire

Choix de traduction appliqués dans tout le jeu.

## Termes conservés en anglais

| Terme | Raison |
|---|---|
| The World | nom du jeu dans le jeu |
| Chaos Gate, Gate Out, Root Town | termes système de « The World », cités tels quels partout |
| Data Drain, Virus Core, Data Flag | idem, termes clés de l'histoire |
| Recorder, Elf's Haven | noms de services en ville, cités dans de nombreux dialogues |
| Mots-clés de zone (*Bursting*, *Aqua Field*…) | le jeu assemble les noms de zone mot par mot |
| Noms propres (personnages, villes, serveurs) | Mac Anu, Dun Loireag, Carmina Gadelica, Fort Ouph, Lia Fail… |
| Mots inventés des sorts | Repth, Vak Kruz, Gan Don, Rue Zot… |
| Noms japonais d'armes | Kikuichimonji, Nihonmaru, Suigetsu… |

## Compétences

Les compétences à préfixe inventé gardent le préfixe et traduisent le mot anglais :
Slash → Entaille, Crack → Fracas, Smash → Choc, Drive → Percée, Break → Brisure, Tornado → Tornade, Doom → Ruine, Tempest → Tempête…
Exemple : *Gan Slash* → *Entaille Gan*.
