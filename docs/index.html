Installer la traduction française de .hack//Infection

  1. Ayez votre propre ISO de .hack//Infection version USA (SLUS-202.67, MD5 eca5b2c41b7833ee38d489002c7aabc4).
  2. Téléchargez dothack-infection-fr.xdelta dans les releases du projet.
  3. Appliquez le patch avec Delta Patcher (sur une copie de l'ISO) ou Rom Patcher JS.
  4. Lancez l'ISO française dans PCSX2.

Questions fréquentes

Le patch FR contient-il le jeu ?
Non. Seules les différences sont distribuées : il faut votre propre copie de .hack//Infection. Aucun lien vers une ISO ne sera donné.

Quelle version de .hack//Infection faut-il ?
La version américaine (NTSC-U, SLUS-202.67). Les versions européenne et japonaise ne sont pas compatibles.

Ça marche sur une vraie PS2 ?
Le patch est testé sur l'émulateur PCSX2. Sur console (OPL), ce n'est pas encore testé.
